# Documentos conservados fuera de la importación

El PDF de Sala subido con nombre J6 contiene J5. Se conserva aquí sin alterar sus bytes, con un nombre que describe su contenido y el error original. La clasificación activa J5 permanece en `pdfs/2026-2027/`.

`data/pdf-archive.json` registra ruta original, destino, SHA-256 y motivo. CI permite esta retirada del conjunto activo solo si el documento original del commit base y la copia archivada coinciden exactamente. Los documentos de esta carpeta no se importan ni publican como jornadas.

No se han eliminado los PDFs históricos ni las versiones anteriores.
